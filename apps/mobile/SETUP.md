# MealaweUserAppRN — Setup & Runbook

React Native + Expo clone of the Ionic `MealaweUserApp`, following
`../MealaweUserApp/docs/react-native-migration-analysis.md`. Behavioural
reference for screens/flows is `../mealaweApp` (modern Ionic 8 rebuild).

## Stack (verified July 2026)

| Layer | Choice |
|---|---|
| Runtime | Expo SDK 57 · React Native 0.86 · React 19.2 · New Architecture |
| Language | TypeScript (strict) |
| Navigation | Expo Router (file-based, `src/app/`) — Stack + `(tabs)` group |
| Styling | NativeWind v5 + Tailwind v4 (`className`) |
| UI kit | Gluestack UI v5 (`src/components/ui/`, provider wired in root layout) |
| State | Zustand (`src/store`) |
| Storage | expo-secure-store (session) + react-native-mmkv v4 |
| Media | expo-video (login hero), expo-image |
| Crypto | crypto-js — AES `session_x` (ported exactly from the Ionic app) |

**Platforms: Android + iOS only.** Web was removed (`platforms: ["ios","android"]`,
no `web` script). `react-native-web` remains only as a transitive peer.

## ⚠️ Pinned `lightningcss` (do not remove)

`package.json` pins `"overrides"/"resolutions": { "lightningcss": "1.30.1" }`.
Expo SDK 57 pulls `1.33.0`, whose AST format breaks NativeWind v5's
`react-native-css` compiler (`failed to deserialize … Specifier`). Keep the pin
until NativeWind v5 leaves preview.

## Run scripts

```bash
npm install            # respects the lightningcss pin + installs native peers
npm run typecheck      # tsc --noEmit
npm run start          # Metro for a Dev Client build (recommended)
npm run start:go       # Metro for Expo Go (JS-only screens; see caveat)
npm run android        # expo run:android — native debug build + install
npm run ios            # expo run:ios — native build + install (macOS only)
npm run prebuild       # regenerate native android/ ios/ projects (expo prebuild --clean)
```

### Expo Go caveat
This app uses native modules that are **not in Expo Go**: `react-native-mmkv`
(Nitro), `expo-video`, Gluestack/Reanimated worklets. Expo Go can load pure-JS
screens but will crash where those modules are used. Use a **Dev Client**
(`npm run android` / EAS build) for full functionality.

## Building & opening natively

Native projects are generated by Expo (CNG) and are git-ignored — regenerate any
time with `npm run prebuild`.

**Android (Windows/Mac/Linux):**
1. Install Android Studio + an SDK + an emulator (or plug in a device with USB debugging).
2. `npm run prebuild` (creates `android/`).
3. Open the `android/` folder in Android Studio, let Gradle sync, press Run — **or** just `npm run android`.
   - App id: `com.mealawe.app`.

**iOS (macOS only):**
1. `npm run prebuild` then `npx pod-install` (CocoaPods).
2. Open `ios/MealaweUserAppRN.xcworkspace` in Xcode and Run — **or** `npm run ios`.

## Environments (local / staging / production)

Full per-environment config is ported from the Ionic app into
`src/config/environments.ts` (server URLs, `api_secret_key` — **staging uses a
different key** — Firebase, Paytm/JusPay, MixPanel, store URLs, fingerprint).
The active profile is chosen by `EXPO_PUBLIC_ENV` (default `production`).

Switch environment via scripts:
```bash
npm run start:local      # http://localhost:5000   (dev server)
npm run start:staging    # AWS staging ELB
npm run start:prod       # https://api.mealawe.com
# native builds: android:local / android:staging / android:prod, ios:staging / ios:prod
```

Override individual keys with `EXPO_PUBLIC_*` (see `.env.example`), e.g. point a
device at your machine: `EXPO_PUBLIC_API_URL=http://192.168.1.43:5000`.
Consume config anywhere via `import { env } from '@/config'` (`env.serverUrl`,
`env.apiSecretKey`, `env.paytm`, `env.firebaseConfig`, …).

## Auth flow (implemented)

```
/index (gate) ──not authed──▶ /welcome (3-slide onboarding + Get Started)
                                     └─▶ /login (video hero, phone → OTP → verify)
                                              ├─ new user ─▶ /register (name/email/referral)
                                              └─ returning ─▶ /(tabs) home
  authed + profile ─────────▶ /(tabs)   (blank home + Log out)
  authed + no profile ──────▶ /register
```

- Real endpoints (`src/services/http/endpoints.ts`): `/authuser/registerPhoneNo`,
  `/authuser/resendOTP`, `/authuser/verifyOTP`, `/authuser/logout`,
  `/api/customerProfile`, `/api/updatecustomerprofile/:id`.
- Every request is AES-encrypted into `{ data_key }` with a per-request
  `session_x` (`src/services/crypto/aes.ts` + `httpClient.ts`) — ported exactly
  from `mealaweApp/apiHttp.service.ts`.
- Session persisted in expo-secure-store; `useAuthStore` hydrates on boot.

## Theming

- Brand palette (light-mode primary): green `#63AB45`/`#518937`, yellow `#FFCA22`,
  cream `#EAE2B7`, deep teal `#042A33`. Source of truth: `src/global.css`.
- Style with tokens: `bg-primary`, `text-foreground`, `bg-secondary`,
  `bg-accent`, `border-border`, plus fixed hues `bg-brand-green` / `bg-brand-yellow`.
- Semantic tokens flip in dark mode; the provider is set to `mode="light"` in
  `_layout.tsx` (change to `"system"` to follow the device).
